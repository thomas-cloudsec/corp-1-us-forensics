1.1 Executive Overview & High-Level Summary

A comprehensive digital forensics and incident response (DFIR) investigation was conducted on host CORP-1-US following alerts indicating database operational anomalies and unauthorized external administrative access.

The evaluation confirms that host CORP-1-US suffered a successful external intrusion resulting in database credential compromise, systematic data exfiltration, database deletion (DROP DATABASE), extortion artifact injection, anti-forensic audit purging, and post-exploitation persistence staging.

The primary root cause was an unsegmented, publicly listening MySQL database daemon (mysqld.exe) bound to 0.0.0.0:3306 combined with permissive wildcard access controls ('root'@'%') and disabled host-level firewall logging.

3.3 Strategic Remediation & Containment Playbook

READY FOR DEPLOYMENT
Step 1: Network Isolation & Loopback Binding my.ini

Reconfigure MySQL daemon in C:\ProgramData\MySQL\MySQL Server 8.0\my.ini to bind exclusively to loopback:

[mysqld]
bind-address = 127.0.0.1
mysqlx-bind-address = 127.0.0.1

Restart database service via PowerShell:

Restart-Service -Name "MySQL80" -Force
Step 2: Database Privilege Revocation & Credential Reset MySQL Console

Revoke wildcard grants and re-create root restricted to localhost:

-- Drop remote administrative accounts
DROP USER IF EXISTS 'root'@'%';
DROP USER IF EXISTS 'admin'@'%';

-- Re-create root restricted to localhost
CREATE USER 'root'@'localhost' IDENTIFIED BY 'STRONG_COMPLEX_PASSWORD_HERE';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'localhost' WITH GRANT OPTION;
FLUSH PRIVILEGES;
Step 3: Windows Host Firewall Enforcement PowerShell Admin

Block port 3306 from external subnets and enable Defender firewall logging:

# 1. Remove permissive rules
Remove-NetFirewallRule -DisplayName "Allow_Any_MySQL_External" -ErrorAction SilentlyContinue

# 2. Add explicit block rule for MySQL port 3306
New-NetFirewallRule -DisplayName "Block_MySQL_Public_Inbound" `
                    -Direction Inbound `
                    -LocalPort 3306 `
                    -Protocol TCP `
                    -Action Block `
                    -Enabled True

# 3. Enable Defender Firewall Logging
Set-NetFirewallProfile -Profile Domain,Private,Public `
                       -LogAllowed True `
                       -LogBlocked True `
                       -LogFileName "%systemroot%\system32\LogFiles\Firewall\pfirewall.log" `
                       -LogMaxSizeKilobytes 4096
Step 4: Persistence Audit & Application Shim Removal CMD / PowerShell

Audit registry for unapproved shims registered via sdbinst.exe and purge:

:: Enumerate registered shims in registry
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Custom" /s

:: Unregister suspicious shim database files if identified
sdbinst.exe -u "C:\Path\To\SuspiciousShim.sdb"
